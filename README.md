db2hackbyxgh.bin is a modified version of the game. If you try to open it in an emulator, you may encounter a "Check Sum Error."

To fix this, open FixCheckSum.exe and load the .bin file. Once the checksum has been fixed, return to the emulator and open the modified game file.

Note: The game may not work correctly on some emulators. I am using Kega Fusion.

In the emulator, click the Load State button and select the 01.gs file.
